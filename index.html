Cutting a 700-million-record pipeline from 6 hours to 2.5

An Azure Data Factory job was reloading everything on every run, which caused bottlenecks and resource contention. I replaced the full load with a Student ID partition-key strategy and split the data into 50-million-row partitions.

The run time dropped from 6 hours to 2.5, and cloud compute costs fell with it.

Azure Data Factory, partitioning, cost optimization

Keeping full history with Slowly Changing Dimensions Type 2

Reports need to show what was true at the time, not only what is true now. I built ETL pipelines that detect changes in source data and write a new versioned row, with start and end dates and an active flag, instead of overwriting the old one.

Indexes on the tracking columns and error handling keep it fast and consistent, so point-in-time reporting works.

SQL, ETL, indexing, error handling

Estimating age from facial expression

My final year project at the Virtual University of Pakistan. I trained a YOLOv4 neural network to estimate a person's age from their face. I annotated the images with LabelImg, trained and fine-tuned the model on Google Colab with Darknet as the backend, and reduced the model weights for better performance. It covers training, evaluation and deployment end to end.

Python, YOLOv4, Google Colab, LabelImg, Darknet, MLlib, neural networks
