# Abdul Sattar, Data Engineer portfolio

A static site: plain HTML, CSS and JavaScript. No build step and no dependencies.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io`.

## Things to check before publishing

- Dates are copied from the resume. Fiverr (Tijgar Software) runs March 2022 to October 2025, which overlaps Digi Float and Wisdom Tech, so confirm them.
- Your phone number is left off the page on purpose. Add it to the Contact section if you want it public.
- To add LinkedIn or GitHub, add a link in the Contact section of `index.html`, next to the email buttons.
- The hero animation and the two project replays are illustrations, not live data. The captions on the page say so.

## Customizing

- Colors and fonts are the variables at the top of `style.css`.
- The animation reads its colors from those same variables.
- Visitors who prefer reduced motion get a still image of the pipeline, finished replays and a fully lit timeline.
